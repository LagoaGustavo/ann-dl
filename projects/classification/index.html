    Sem vazamento.

    • O resultado tem 50 colunas e 0 NaN, a mesma estrutura do EDA.
    • O corte de 1% do min_frequency agora é calculado em 20823 linhas, e mesmo assim nenhuma categoria mudou de balde.
    • O teste só é carregado com prepara(teste=True), chamado apenas pelo script do passo 5.

    Correções do EDA aplicadas aqui. Mexer na pasta do EDA mudaria a data dela, então as correções ficam nesta entrega:

    1. No item 4C do EDA, occupation aparece com 15 colunas. São 14, e a soma dos blocos one-hot dá 45 + 5 numéricas = 50 (a lista completa sai em s0_partida.py).
    2. As decisões de descarte e o diagnóstico de vazamento de capital-gain foram medidos no dataset inteiro. Aqui, todas as decisões (validação, limiar, configuração) usam só o sub-treino e a validação.
    3. A promessa do EDA, "treinar com e sem capital-gain", é cumprida na seção 6.

    Decidido antes de treinar. Estes três pontos estão em comum.py desde o primeiro commit da entrega (0b77e07), antes de qualquer commit com código de treino. Todos os commits foram gravados em 17/nov: a ordem deles registra a sequência das etapas, não o horário de cada execução.

    • Métrica principal: PR-AUC da classe >50K (average precision).
      • Só 24.09% são positivos, e "sempre ≤50K" já acerta 75.91%, então a acurácia não discrimina.
      • A PR-AUC não depende de limiar e tem como piso a prevalência (0.241).
      • É a métrica honesta para positivo minoritário.
    • Critério de sucesso. A PR-AUC média da rede no teste precisa ser ≥ PR-AUC do melhor baseline obrigatório + 0.01, e essa diferença precisa ser maior que o desvio padrão da rede entre seeds. O melhor baseline obrigatório é o trivial ou o linear, escolhido pela validação.
    • Custo dos erros (para o limiar). O cenário é uma triagem de público de alta renda para uma oferta financeira.
      • Um FN (pessoa >50K não abordada) é uma venda perdida.
      • Um FP (pessoa ≤50K abordada) é um contato desperdiçado, mais barato.
      • Fixamos C_FN = 3 × C_FP.
      • Com probabilidades calibradas, o limiar ótimo seria C_FP/(C_FP + C_FN) = 0.25.
      • Mas a perda com pos_weight distorce as probabilidades. Por isso o limiar é escolhido varrendo 0.01…0.99 na validação e pegando o de menor custo médio (3·FN + FP)/n. Esse procedimento não depende de calibração.

    """Módulo comum da entrega 2 (classificação) — importável, não executa nada pesado no import.

Reaproveita o pipeline do EDA (docs/projects/eda/code/pipeline.py) SEM copiá-lo: mesmo
arquivo de dados, mesma limpeza, mesmo split treino/teste (80/20 estratificado, seed 42).

    from comum import prepara
    d = prepara()            # sub-treino + validação (o teste fica de fora)
    d = prepara(teste=True)  # só no passo 5, depois de todas as escolhas

A validação sai de DENTRO do treino do EDA (20% estratificado, mesma seed) e o
pré-processador é ajustado SÓ no sub-treino — a validação e o teste são apenas
transformados, então nenhuma estatística (mediana, média, desvio, categorias raras) vem
deles.
"""
import sys
from pathlib import Path
from types import SimpleNamespace

import numpy as np
import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt  # noqa: E402
from sklearn.metrics import (accuracy_score, average_precision_score,  # noqa: E402
                             confusion_matrix, f1_score,
                             precision_recall_fscore_support, roc_auc_score)
from sklearn.model_selection import train_test_split  # noqa: E402

BASE = Path(__file__).resolve().parent
sys.path.insert(0, str(BASE))
sys.path.insert(1, str(BASE.parents[1] / "eda" / "code"))  # pipeline.py do EDA
from pipeline import (CATEGORICAL, NUM_PLAIN, NUM_SKEWED, SEED,  # noqa: E402
                      build_preprocessor, load_clean, split)

# o console do Windows (cp1252) não imprime "≤", "—" e "×"
if hasattr(sys.stdout, "reconfigure"):
    sys.stdout.reconfigure(encoding="utf-8")

FIG = BASE.parent / "figures"
FIG.mkdir(exist_ok=True)

# mesma identidade visual do EDA (eda.py:28-34)
CORES = ["#E8A13D", "#C75146", "#6B8F3D", "#33658A", "#7A6C8F"]  # âmbar, telha, oliva, aço, lilás
COR_CLASSE = {0: CORES[3], 1: CORES[0]}
ROTULO = {0: "≤50K", 1: ">50K"}
plt.rcParams.update({
    "axes.spines.top": False, "axes.spines.right": False,
    "axes.grid": True, "grid.alpha": 0.25, "figure.dpi": 110,
})

COLUNAS_BRUTAS = NUM_PLAIN + NUM_SKEWED + CATEGORICAL   # as 12 features depois da limpeza

# ------------------------------------------------------------------ PASSO 0 (antes de treinar)
# Métrica principal: PR-AUC (average precision) da classe >50K. O alvo tem 24.09% de
# positivos (EDA 1C): "sempre ≤50K" já acerta 75.91%, então acurácia não discrimina; a
# PR-AUC não depende de limiar e tem como piso a prevalência.
METRICA = "PR-AUC (average precision) da classe >50K"
# Critério de sucesso: PR-AUC média (seeds) da rede no TESTE >= PR-AUC do melhor baseline
# obrigatório (trivial ou linear, escolhido na validação) + MARGEM, e a diferença maior que
# o desvio padrão da rede entre seeds.
MARGEM = 0.01
# Custo dos erros (para o limiar): cenário de triagem de público de alta renda para uma
# oferta financeira — deixar passar uma pessoa >50K (FN) é uma venda perdida; abordar uma
# pessoa ≤50K (FP) é um contato desperdiçado, mais barato. Assumimos C_FN = 3 × C_FP.
C_FN, C_FP = 3.0, 1.0
LIMIARES = np.round(np.arange(0.01, 1.00, 0.01), 2)

# Seeds: busca (passo 4) com 3 seeds; avaliação final (passo 5) com 5.
SEEDS_BUSCA = [42, 43, 44]
SEEDS_FINAIS = [42, 43, 44, 45, 46]

# Configuração congelada no fim do passo 4 (escolhida SÓ pela validação). O passo 5 usa
# exatamente esta. Vencedora da busca: maior PR-AUC média de validação, 0.7773 ± 0.0039
# (3 seeds) entre 27 configurações — e a menor rede entre as que empatam dentro de 1 dp.
CONFIG_ESCOLHIDA = {"larguras": (64,), "lr": 3e-3, "dropout": 0.3}


def secao(txt):
    print("\n" + "=" * 80 + f"\n{txt}\n" + "=" * 80, flush=True)


def salva(fig, nome):
    fig.savefig(FIG / nome, bbox_inches="tight")
    plt.close(fig)


def preprocessador(sem=()):
    """O ColumnTransformer do EDA, sem alterar nenhum passo; `sem` tira colunas (ablação)."""
    prep = build_preprocessor()
    if sem:
        prep.transformers = [
            (nome, t, [c for c in cols if c not in sem])
            for nome, t, cols in prep.transformers
            if [c for c in cols if c not in sem]
        ]
    return prep


def prepara(teste=False, sem=()):
    """Split do EDA + validação estratificada dentro do treino; prep ajustado só no sub-treino."""
    df = load_clean()
    X_train, X_test, y_train, y_test = split(df)                    # o MESMO split do EDA
    X_tr, X_val, y_tr, y_val = train_test_split(
        X_train, y_train, test_size=0.2, stratify=y_train, random_state=SEED)

    prep = preprocessador(sem)
    d = SimpleNamespace(
        X_tr=X_tr, X_val=X_val,
        y_tr=y_tr.to_numpy(), y_val=y_val.to_numpy(),
        Z_tr=prep.fit_transform(X_tr).astype("float32"),             # fit SÓ no sub-treino
        Z_val=prep.transform(X_val).astype("float32"),
        prep=prep, n_train_eda=len(X_train),
    )
    d.nomes = list(prep.get_feature_names_out())
    n_pos = int(d.y_tr.sum())
    d.pos_weight = (len(d.y_tr) - n_pos) / n_pos                   # N_neg / N_pos do sub-treino
    if teste:                                                       # só no passo 5
        d.X_te, d.y_te = X_test, y_test.to_numpy()
        d.Z_te = prep.transform(X_test).astype("float32")
    return d


def custo(y, p, t):
    """Custo médio por pessoa no limiar t: (C_FN·FN + C_FP·FP) / n."""
    pred = p >= t
    fn = np.sum((y == 1) & ~pred)
    fp = np.sum((y == 0) & pred)
    return (C_FN * fn + C_FP * fp) / len(y)


def limiar_por_custo(y, p):
    """Varre os limiares 0.01…0.99 e devolve (melhor limiar, custos de cada limiar)."""
    custos = np.array([custo(y, p, t) for t in LIMIARES])
    return float(LIMIARES[int(np.argmin(custos))]), custos


def avalia(y, p, t):
    """Todas as métricas pedidas para classificação, num limiar t."""
    pred = (p >= t).astype(int)
    prec, rec, f1, _ = precision_recall_fscore_support(y, pred, labels=[0, 1], zero_division=0)
    tn, fp, fn, tp = confusion_matrix(y, pred, labels=[0, 1]).ravel()
    return {
        "pr_auc": average_precision_score(y, p), "roc_auc": roc_auc_score(y, p),
        "limiar": t, "acuracia": accuracy_score(y, pred),
        "f1_macro": f1_score(y, pred, average="macro", zero_division=0),
        "prec_0": prec[0], "rec_0": rec[0], "f1_0": f1[0],
        "prec_1": prec[1], "rec_1": rec[1], "f1_1": f1[1],
        "custo": custo(y, p, t), "tn": tn, "fp": fp, "fn": fn, "tp": tp,
    }


def linha(nome, m, chaves=("pr_auc", "roc_auc", "limiar", "acuracia", "f1_macro",
                           "prec_1", "rec_1", "f1_1", "custo")):
    return f"{nome:34} | " + " | ".join(f"{k} {m[k]:.4f}" for k in chaves)

    2. The network¶

    A rede base dos passos 2 e 3 é 50 → 64 → 32 → 1. A rede final, escolhida no passo 4, é 50 → 64 → 1.

    flowchart LR
    x["Entrada<br/>50 features"] --> h1["Oculta<br/>64 · ReLU<br/>(dropout 0.3 na final)"]
    h1 -.base.-> h2["Oculta 2<br/>32 · ReLU"]
    h2 -.-> out["Saída<br/>1 logit"]
    h1 -->|final| out
    Escolha Por quê
    Camadas ocultas base: 2 (64, 32); final: 1 (64) O dado é tabular e pequeno: o PCA do EDA mostra 43 direções reais nas 50 colunas. Não há fronteira simples (a silhueta pela renda é no máximo 0.253 em PCA, t-SNE e UMAP), então vale ter não linearidade, mas não profundidade. A busca do passo 4 confirmou que uma camada de 64 basta.
    Larguras 64 → 32 (base) Afunila das 50 entradas para poucas dezenas. Larguras de 128 e 3 camadas foram testadas no passo 4 e não melhoraram a validação.
    Ativação ReLU A derivada é 1 para x > 0. A sigmoide tem derivada ≤ 0.25 e encolhe o gradiente camada a camada.
    Inicialização He (Kaiming normal) nas ocultas; Glorot na saída; vieses = 0 He mantém a variância das ativações quando a ReLU zera metade delas. A saída é linear, então usa Glorot.
    Saída 1 unidade, sem sigmoide (logit) Classificação binária. A probabilidade σ(u) só é calculada na hora de prever.
    Perda BCEWithLogitsLoss(pos_weight = 15806/5017 = 3.15) Junta sigmoide e entropia cruzada com o truque log-sum-exp, que é numericamente estável. O gradiente na saída é o mesmo σ(u) − y que deduzimos no exercício MLP, com os positivos pesando 3.15× para compensar o desbalanceamento. O peso é calculado no sub-treino.

    Parâmetros contra linhas de treino.

    Rede Parâmetros Linhas de treino Parâmetros por linha
    base 50 → 64 → 32 → 1 3264 + 2080 + 33 = 5377 20823 0.258
    final 50 → 64 → 1 3264 + 65 = 3329 20823 0.160

    As duas redes têm bem menos parâmetros que linhas. Mesmo assim, a rede base decora o sub-treino se for treinada por tempo demais (passo 3): a capacidade não é só a contagem de parâmetros.

    """A rede do passo 2: MLP em PyTorch que devolve LOGITS (sem sigmoide no fim)."""
import torch
from torch import nn


class MLP(nn.Module):
    """Linear → [BatchNorm] → ReLU → [Dropout], repetido por camada oculta; saída = 1 logit.

    - ReLU nas ocultas: derivada 1 para x > 0, sem a saturação da sigmoide/tanh (derivada
      ≤ 0.25 / ≤ 1) que encolhe o gradiente camada a camada;
    - inicialização de He (Kaiming normal) nas camadas seguidas de ReLU: mantém a variância
      das ativações estável quando metade delas é zerada pela ReLU; Glorot (Xavier) na saída,
      que é linear; vieses começam em zero;
    - a saída é UM logit u: a probabilidade é σ(u), aplicada só na hora de prever, porque a
      perda BCEWithLogitsLoss junta sigmoide + entropia cruzada de forma numericamente estável.
    """

    def __init__(self, d_entrada, larguras=(64, 32), dropout=0.0, batchnorm=False):
        super().__init__()
        camadas, d = [], d_entrada
        for h in larguras:
            camadas.append(nn.Linear(d, h))
            if batchnorm:
                camadas.append(nn.BatchNorm1d(h))
            camadas.append(nn.ReLU())
            if dropout > 0:
                camadas.append(nn.Dropout(dropout))
            d = h
        self.ocultas = nn.Sequential(*camadas)
        self.saida = nn.Linear(d, 1)
        self._inicializa()

    def _inicializa(self):
        for m in self.ocultas.modules():
            if isinstance(m, nn.Linear):
                nn.init.kaiming_normal_(m.weight, nonlinearity="relu")
                nn.init.zeros_(m.bias)
        nn.init.xavier_normal_(self.saida.weight)
        nn.init.zeros_(self.saida.bias)

    def forward(self, x):
        return self.saida(self.ocultas(x)).squeeze(1)      # (N,) logits


def conta_parametros(modelo):
    return sum(p.numel() for p in modelo.parameters() if p.requires_grad)


def descreve(larguras, d_entrada):
    """Ex.: '50 → 64 → 32 → 1'."""
    return " → ".join(str(x) for x in (d_entrada, *larguras, 1))

    """O loop de treino do passo 3: mini-batch + AdamW + parada antecipada pela validação.

Segue o esqueleto do enunciado (best / wait / patience / recarregar os melhores pesos),
com os pesos guardados em memória (copy.deepcopy do state_dict) em vez de um arquivo.
"""
import copy

import numpy as np
import torch
from torch import nn
from sklearn.metrics import average_precision_score

from modelo import MLP

PADRAO = dict(
    larguras=(64, 32),   # passo 2
    lr=1e-3,             # passo 3: padrão de Adam para MLP tabular (página Optimization)
    wd=0.0,              # weight decay (AdamW, desacoplado); 0 = sem regularização
    dropout=0.0,
    batchnorm=False,
    batch=256,           # ~82 passos por época em 20823 linhas
    max_epocas=200,      # teto folgado: a parada antecipada termina bem antes
    paciencia=15,        # épocas sem melhorar a perda de validação antes de parar
)

torch.set_num_threads(4)


def otimizador(modelo, lr, wd):
    """AdamW com weight decay só nas MATRIZES de pesos (vieses e BatchNorm ficam de fora)."""
    decai = [p for p in modelo.parameters() if p.ndim >= 2]
    nao_decai = [p for p in modelo.parameters() if p.ndim < 2]
    return torch.optim.AdamW([
        {"params": decai, "weight_decay": wd},
        {"params": nao_decai, "weight_decay": 0.0},
    ], lr=lr)


@torch.no_grad()
def probabilidades(modelo, Z):
    modelo.eval()
    return torch.sigmoid(modelo(torch.from_numpy(Z))).numpy()


def treina(d, cfg=None, seed=42, parada=True):
    """Treina uma MLP em d.Z_tr e para pela perda de validação, restaurando os melhores pesos.

    Devolve (modelo com os melhores pesos, histórico por época, melhor época).
    """
    cfg = {**PADRAO, **(cfg or {})}
    torch.manual_seed(seed)
    np.random.seed(seed)
    gerador = torch.Generator().manual_seed(seed)

    X_tr, y_tr = torch.from_numpy(d.Z_tr), torch.from_numpy(d.y_tr.astype("float32"))
    X_val, y_val = torch.from_numpy(d.Z_val), torch.from_numpy(d.y_val.astype("float32"))

    modelo = MLP(X_tr.shape[1], cfg["larguras"], cfg["dropout"], cfg["batchnorm"])
    perda = nn.BCEWithLogitsLoss(pos_weight=torch.tensor(d.pos_weight, dtype=torch.float32))
    opt = otimizador(modelo, cfg["lr"], cfg["wd"])

    hist = {"treino": [], "val": [], "val_prauc": []}
    melhor, espera, melhor_ep, melhores_pesos = float("inf"), 0, 0, None
    n = len(X_tr)
    for epoca in range(1, cfg["max_epocas"] + 1):
        modelo.train()                                   # liga dropout / BatchNorm de treino
        ordem = torch.randperm(n, generator=gerador)
        for i in range(0, n, cfg["batch"]):
            idx = ordem[i:i + cfg["batch"]]
            opt.zero_grad()
            perda(modelo(X_tr[idx]), y_tr[idx]).backward()
            opt.step()

        modelo.eval()                                    # desliga dropout; BN usa médias globais
        with torch.no_grad():
            p_tr = perda(modelo(X_tr), y_tr).item()      # treino medido em modo eval, comparável
            u_val = modelo(X_val)
            p_val = perda(u_val, y_val).item()
        hist["treino"].append(p_tr)
        hist["val"].append(p_val)
        hist["val_prauc"].append(average_precision_score(d.y_val, torch.sigmoid(u_val).numpy()))

        if p_val < melhor:
            melhor, espera, melhor_ep = p_val, 0, epoca
            melhores_pesos = copy.deepcopy(modelo.state_dict())   # cópia, não referência
        else:
            espera += 1
            if parada and espera == cfg["paciencia"]:
                break

    modelo.load_state_dict(melhores_pesos)
    return modelo, hist, melhor_ep

    """Passo 4 — regularização e busca de hiperparâmetros, TUDO decidido na validação.

A) A mesma rede (64, 32), lr 1e-3, mudando UM fator por vez: nenhuma regularização,
   weight decay (2 valores), dropout, BatchNorm, weight decay + dropout. 3 seeds cada.
B) Busca em grade: largura/profundidade × learning rate × regularização (24 combinações,
   3 delas iguais a variantes da parte A — 27 configurações únicas no total).
O critério de escolha é a PR-AUC média de validação nas 3 seeds (empate → rede menor).
Gera a Figura 2 e o arquivo busca_resultados.csv.
"""
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from comum import BASE, CORES, SEEDS_BUSCA, prepara, salva, secao
from modelo import MLP, conta_parametros, descreve
from treino import treina

d = prepara()
D = d.Z_tr.shape[1]


def roda(nome, cfg, parte):
    res = []
    for s in SEEDS_BUSCA:
        _, h, ep = treina(d, cfg, seed=s)
        res.append((h["val_prauc"][ep - 1], h["val"][ep - 1], h["treino"][ep - 1], ep))
    pr, lv, lt, ep = map(np.array, zip(*res))
    larg = cfg.get("larguras", (64, 32))
    linha = {
        "parte": parte, "config": nome, "arquitetura": descreve(larg, D),
        "parametros": conta_parametros(MLP(D, larg, cfg.get("dropout", 0),
                                           cfg.get("batchnorm", False))),
        "lr": cfg.get("lr", 1e-3), "wd": cfg.get("wd", 0.0), "dropout": cfg.get("dropout", 0.0),
        "batchnorm": cfg.get("batchnorm", False),
        "prauc_val_media": pr.mean(), "prauc_val_dp": pr.std(ddof=1),
        "perda_val": lv.mean(), "gap_val_menos_treino": (lv - lt).mean(),
        "melhor_epoca_media": ep.mean(), "cfg": cfg,
    }
    print(f"{parte} | {nome:42} | PR-AUC val {pr.mean():.4f} ± {pr.std(ddof=1):.4f} | "
          f"perda val {lv.mean():.4f} | gap {linha['gap_val_menos_treino']:+.4f} | "
          f"época {ep.mean():5.1f} | {linha['parametros']} parâmetros", flush=True)
    return linha


secao("4A — UM FATOR POR VEZ (rede 64-32, lr 1e-3, 3 seeds)")

    "nenhuma": {},
    "weight decay 0.01": {"wd": 1e-2},
    "weight decay 0.1": {"wd": 1e-1},

    "BatchNorm": {"batchnorm": True},
    "weight decay 0.1 + dropout 0.3": {"wd": 1e-1, "dropout": 0.3},
}
linhas = [roda(n, c, "A") for n, c in VARIANTES.items()]


def chave(cfg):
    c = {"larguras": (64, 32), "lr": 1e-3, "wd": 0.0, "dropout": 0.0, "batchnorm": False, **cfg}
    return (tuple(c["larguras"]), c["lr"], c["wd"], c["dropout"], c["batchnorm"])


ja_rodadas = {chave(l["cfg"]): l for l in linhas}

secao("4B — BUSCA: largura/profundidade × lr × regularização (3 seeds cada)")
REGS = {"wd 0.1": {"wd": 1e-1}, "dropout 0.3": {"dropout": 0.3},
        "wd 0.1 + dropout 0.3": {"wd": 1e-1, "dropout": 0.3}}

                ja_rodadas[chave(cfg)]["parte"] = "A+B"
                print(f"B | {nome:42} | = variante da parte A (não repetida)")
                continue
            linhas.append(roda(nome, cfg, "B"))

tab = pd.DataFrame(linhas)
tab = tab.sort_values(["prauc_val_media", "parametros"], ascending=[False, True])
tab.drop(columns="cfg").to_csv(BASE / "busca_resultados.csv", index=False, float_format="%.4f")

secao(f"4 — TABELA ORDENADA PELA PR-AUC DE VALIDAÇÃO ({len(tab)} configurações únicas testadas)")
cols = ["parte", "config", "parametros", "prauc_val_media", "prauc_val_dp", "perda_val",
        "gap_val_menos_treino", "melhor_epoca_media"]
print(tab[cols].to_string(index=False, float_format=lambda v: f"{v:.4f}"))
top = tab.iloc[0]
empate = tab[tab.prauc_val_media >= top.prauc_val_media - top.prauc_val_dp]
print(f"\nmelhor: {top.config} | PR-AUC val {top.prauc_val_media:.4f} ± {top.prauc_val_dp:.4f}")
print(f"configs a menos de 1 dp da melhor: {len(empate)}")
escolhida = tab.iloc[0]
print("ESCOLHIDA (maior PR-AUC média de validação):", escolhida.config, "->", escolhida.cfg)

# ---------------------------------------------------------------- Figura 2
fig, (a, b) = plt.subplots(1, 2, figsize=(13, 4.6), layout="constrained",

    5. Test evaluation¶

    Retreino. A configuração congelada foi retreinada com 5 seeds (42–46) no mesmo sub-treino, cada uma com parada antecipada na mesma validação.

    • As seeds 42–44 reproduzem exatamente as corridas da busca; 45 e 46 são novas.
    • As redes rodaram 55, 71, 62, 58 e 48 épocas e restauraram as épocas 40, 56, 47, 43 e 33 (média de 43.8).
    • O limiar de cada seed foi escolhido na validação, pelo custo: 0.53, 0.52, 0.53, 0.55 e 0.50.
    • Os baselines foram ajustados no mesmo sub-treino, com limiar também escolhido na validação.
    • Só então o teste foi avaliado, uma vez. Nenhuma escolha (configuração, limiar, época) usou o teste.

    Por que o limiar fica em ~0.5 e não em 0.25. Treinar com pos_weight = 3.15 já equivale a pesar o FN cerca de 3 vezes mais que o FP.

    • Quem sai multiplicado por ~3.15 são as chances p/(1−p) que a rede devolve, não as probabilidades. O logit fica deslocado em ln 3.15 ≈ 1.15.
    • O limiar 0.5 na saída (chance 1) corresponde à chance real 1/3.15, ou seja, p = 1/(1 + 3.15) ≈ 0.24.
    • O limiar de custo 0.25 na probabilidade real (chance 1/3) vira chance 3.15/3 ≈ 1.05 na saída, ou seja, ≈ 0.51.
    • Por isso a varredura na validação cai entre 0.50 e 0.55.

    A Figura 3 mostra que o custo é plano entre ~0.45 e 0.55, então a escolha exata pouco importa.

from sklearn.metrics import (average_precision_score, classification_report,
                             precision_recall_curve, roc_curve)

from comum import (C_FN, C_FP, COLUNAS_BRUTAS, CONFIG_ESCOLHIDA, CORES, LIMIARES, MARGEM,

                   salva, secao)

assert CONFIG_ESCOLHIDA is not None, "congele a configuração no passo 4 antes do teste"

cfg_total = {**PADRAO, **cfg}
print("cfg:", cfg_total)

      conta_parametros(MLP(D, cfg_total["larguras"], cfg_total["dropout"])))

    7. Conclusion¶

    A rede valeu a pena? Contra os modelos mais simples, sim.

    • Ela supera a logística por +0.045 de PR-AUC no teste, cerca de 14 vezes a variação entre seeds.
    • Também reduz o custo por pessoa em 7.7% e mantém a vantagem mesmo sem as colunas de capital. Ou seja, aprende interações que o modelo linear não aprende.
    • Ela não é o melhor modelo para este problema. O HistGradientBoosting, sem tuning, fica 0.0445 acima.
    • Se o objetivo fosse colocar um modelo em produção, usaríamos árvores. A MLP só se justificaria se precisasse fazer parte de um sistema maior treinado por gradiente.

    Limitações.

    • Um único split. Os ± são variação de seed, não de amostra. Com validação cruzada, a incerteza seria maior.
    • Probabilidades descalibradas. O pos_weight desloca o logit em ≈ ln 3.15, então "p = 0.53" não significa 53% de chance. Para usar a probabilidade em si, seria preciso calibrar na validação. Uma saída é subtrair ln(pos_weight) do logit, que é a correção de prior da página Imbalance. Outra é ajustar um Platt scaling, σ(a·u + b). Temperature scaling sozinho, σ(u/T), não resolve: ele muda a escala do logit, mas não remove o deslocamento.
    • Viés de seleção. A configuração é a melhor de 27 na validação.
    • Parada pela perda. É conservadora nesta rede (passo 3). Parar pela PR-AUC poderia render um pouco mais.
    • O custo 3:1 é uma suposição de cenário, não um dado.
    • Dados antigos e truncados. São do censo dos EUA de 1994, com valores no teto (age 90, hours-per-week 99, capital-gain 99999). O limite de 50K não foi corrigido pela inflação.

    Quem seria afetado por um erro. Se este modelo decidisse acesso a crédito, a uma oferta ou a um benefício, os erros não se distribuem por igual.

    • Um >50K é perdido (FN) duas vezes mais entre as mulheres (FNR 22.8%) que entre os homens (10.6%). O mesmo acontece entre pessoas negras (20.2%) e brancas (11.9%), e em 38.6% dos menores de 30.
    • Um ≤50K é marcado como >50K (FP) em 28.6% dos homens contra 6.3% das mulheres.
    • Remover sex, race e relationship não custa desempenho. Mas isso não resolve: marital-status, occupation e hours-per-week carregam a mesma informação. Equidade exigiria medir e restringir FNR/FPR por grupo, não só esconder colunas.

    Com mais tempo:

    • validação cruzada no treino;
    • calibração das probabilidades;
    • parada antecipada pela PR-AUC;
    • embeddings para as categóricas, em vez de one-hot;
    • comparar com um boosting ajustado e com um ensemble das 5 seeds;
    • avaliar restrições de equidade (taxas de erro iguais entre grupos).
